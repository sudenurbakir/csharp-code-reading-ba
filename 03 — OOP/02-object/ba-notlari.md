# BA Notları

Class ve Object arasındaki farkı anlamak önemlidir.

```text
Product
   ↓
Class / Şablon
   ↓
Laptop → Object
Telefon → Object
```

Class:

> Sistemde ürün kavramının nasıl temsil edildiğini tanımlar.

Object:

> Bu kavramın gerçek bir örneğini temsil eder.

### BA Açısından

Bir class'tan birden fazla object oluşturulabilir.

Örneğin `Customer` class'ından:

* Ahmet
* Ayşe
* Mehmet

gibi farklı müşteri nesneleri oluşturulabilir.

Kod okurken:

> "Bu class neyi temsil ediyor ve bu object hangi gerçek veriyi temsil ediyor?"

sorusunu sorabiliriz.
