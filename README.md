# C# Code Reading for Business Analysts

Bu depo, İş Analistlerinin C# kodunu okuma, anlama ve iş diline çevirme becerisini geliştirmesi amacıyla hazırlanmıştır.

## Amaç

Kod yazmak değil; mevcut C# kodunu okuyabilmek, içinden iş kurallarını çıkarabilmek ve bunları net bir şekilde dokümante edebilmektir.

## Bu Repo Ne Sağlar?

- Kod ile iş gereksinimleri arasındaki ilişkiyi kurabilme
- Developer’larla daha sağlıklı iletişim kurabilme
- Teknik detayları business diline çevirebilme
- Tutarlı ve profesyonel dokümantasyon üretebilme

## Klasör Yapısı

| Klasör | Açıklama |
|--------|----------|
| **01-Temel-Kavramlar** | C#’ın temel yapılarının İş Analisti gözüyle açıklaması |
| **02-Kod-Analiz-Ornekleri** | Gerçekçi kod parçalarının detaylı analizi |
| **03-Is-Kurallari** | Koddan çıkarılan iş kuralları |
| **04-Dokumantasyon-Sablonlari** | Tutarlı dokümantasyon için hazır şablonlar |
| **05-Karsilastirmalar-ve-Iyi-Pratikler** | Yaygın yaklaşımların karşılaştırılması ve iyi pratikler |
| **06-Terimler-Sozlugu** | Sık kullanılan terimlerin açıklamaları |
